## 本轮落地并验证

- 核查工单：系统自动发现的未验证或失败运行仅记为 `suggested`。所有者须在前端二次确认，`POST /api/runs/{run_id}/approvals` 才把工单置为 `open`；拒绝不会开单。`review_approvals.run_id` 唯一，重复确认返回同一工单；事件日志保存决定。旧数据库中历史 `open` 工单未被自动改写。
- 运行控制：前端取消按钮调用真实取消接口。流断开时按事件 ID 补读，不重新执行模型；若尚未收到 `started`，用服务端归属受限的幂等键定位已有运行。运行中的幂等键暂存于浏览器当前标签页，刷新页面后查询状态并重订阅事件；跨设备恢复及尚未创建运行时的异常仍需现场演练。
- 身份安全：新密码采用 Argon2id，旧 bcrypt 在成功登录后迁移；新注册密码至少 12 字符。访问 JWT 改为 15 分钟，并带会话 ID 和随机 `jti`。刷新凭据为可轮换的随机值，仅以 SHA-256 保存于数据库；HttpOnly/SameSite Cookie，生产开启 Secure。刷新及退出要求同源/允许来源 Origin 和与会话绑定的 CSRF Header；退出吊销刷新会话及关联访问令牌。前端不再把新访问令牌持久写入 `localStorage`，旧本地令牌读取一次后删除。登录页不再预填/展示默认管理员口令。部署前仍须做浏览器安全验收和密钥轮换演练。
- 健康接口不再把模型加载 traceback 直接返回给浏览器；内存保护原因仍可见。现有进程未调用 Doubao/Tavily 做本轮测试。
- 本机 8001 服务重启后预热成功：活动快照 920 份（918 文本、2 仅图像），30,406 切块、17,957 页图；付费开关与真实 Web 搜索配置保持原样。重启前数据库在线备份：`output/backups/2026-09-24-pre-approval-upgrade.sqlite3`，完整性检查 `ok`。内存保护一度挡住预热；经用户授权，停止两个 IndexTTS WebUI 后恢复。未停止其他项目的适配器或业务 API。
- 自动测试：`python -m pytest -q` 为 450 passed、4 skipped、12 subtests passed；前端 `npm run build` 通过；`docker compose config --quiet` 仅在一次性占位强凭据下通过，真实生产凭据未设置；`docker buildx build --check` 无告警。HTTP 烟测：页面 200、缺 CSRF 的刷新 403、未认证运行查找 401。没有执行完整 Docker 镜像构建/容器上线。
