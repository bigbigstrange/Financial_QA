# 2 分 30 秒演示视频脚本

> 目标：让面试官在 2 分半内看到「能跑 → 能溯源 → 有边界 → 有工程」四件事。
> 录制前把所有东西预热好，录的时候不要现装依赖。

---

## 录屏前准备（5 分钟）

```bash
# 1) 起容器（已构建过，几秒起）
docker compose -f docker-compose.demo.yml up -d

# 2) 确认健康
curl http://127.0.0.1:8002/api/health

# 3) 浏览器准备三个标签页
#    A: http://127.0.0.1:8002          （产品界面）
#    B: https://github.com/bigbigstrange/Financial_QA   （仓库）
#    C: docs/evidence/trace.png         （节点时序图，用图片查看器打开）

# 4) 终端窗口放在屏幕下方，字号调到 18pt 以上
```

**清屏**：浏览器 F11 全屏，隐藏书签栏；终端 `clear`。

## 分镜表

| 时间 | 画面 | 旁白（照读即可） |
|---|---|---|
| **0:00-0:15** | 浏览器打开仓库首页（已滚到顶部，显示徽章 + 架构图） | 「这是一个金融文档问答的 Agent 平台。仓库里 490 个测试、CI 全绿，覆盖率 67%。」 |
| **0:15-0:35** | 切到产品页面，登录（admin / demo-admin-2026），进入问答 | 「它解决的不是"能不能答"，是"敢不敢用"——所以我做了三件事：证据链、双校验、预算熔断。」 |
| **0:35-1:05** | 输入问题：**"稳盈货币基金A的起购金额是多少？"**，回车等结果 | 「注意看：回答下面挂着引用，点开能看到原文块和页码。答不出就拒答，不编。」 |
| **1:05-1:25** | 输入第二个问题：**"信用卡年费是多少？"** | 「知识库里没有这个问题——它直接拒答，而不是硬凑一个答案。这条边界是服务端强制的，不是提示词。」 |
| **1:25-1:50** | 切到 trace.png，用鼠标指着节点 | 「这是一次真实请求的 12 个节点：检索 12 条 → 评分全不通过 → 重写查询 → 再检索 → 最后 give_up。两轮重试是硬上限。」 |
| **1:50-2:10** | 切回仓库，滚动到「评测」段，指着 metrics 表 | 「指标不是我自己写的：一条命令复现，结果文件随仓库提交。唯一没命中的题我也写在 README 里了。」 |
| **2:10-2:30** | 切到「评测与边界」段落，指到 6 条"未做到" | 「最后这部分最重要：500 题准确率门禁没通过、多租户 ACL 没做、Docker 生产部署没验收——**这些我都不宣称**。」 |

**收尾字幕**：`github.com/bigbigstrange/Financial_QA`

## 讲解要点（不要背稿，记这 3 句）

1. **「不是让它会答，是让它该拒的时候拒。」**
2. **「数字不是我写的，是脚本跑出来的，你能复现。」**
3. **「做不到的我都写在 README 里了。」**

---

## 录制参数

- 分辨率 1920×1080，30fps
- 麦克风离嘴 15cm，先录 10 秒静音测底噪
- 语速比平时慢 10%，句子之间停 0.5 秒（方便后期剪）
- **一次录不完就分段录**，最后拼；不要为了"一条过"反复重来

## 剪辑清单

- [ ] 开头 3 秒加标题卡：项目名 + 一句话定位
- [ ] 关键结论加字幕（拒答、12 节点、67%、490 tests）
- [ ] 结尾 5 秒放仓库地址二维码
