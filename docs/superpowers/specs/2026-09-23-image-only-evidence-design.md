# 纯图片页证据召回设计

日期：2026-09-23。状态：已实施并通过候选本地功能验证；全量 17,957 页编码完成，未激活候选库，相关性／准确率未达标。验收详见 baseline 运行记录。

## 1. 目标与事实依据

用户需要把已有文档中的图表真正用于检索，并能打开对应原图核验，而不是仅保存图片文件。用户已同意优先补齐图像证据召回，不先新增 OCR 服务。

本次沿用 `specs/001-complete-local-corpus/spec.md` 和 `.specify/memory/constitution.md` 的范围与安全边界。历史执行结果以 `docs/baseline/2026-09-22-local-completion-runbook.md` 为准。

当前候选快照为 `snap_2e0f216e294bd7baba5709c6a62b691b`，含 920 份文档、30,406 个切块和 17,957 张页图。已有视觉索引覆盖 17,813 张与文字切块关联的页图。其余 144 页中，137 页没有解析块、7 页只有无文本图形；实际看图已确认其中至少两页包含有效图表，不能当作空白页排除。

根因：`ChineseVisionRetriever.page_items()` 从文字切块枚举页面，`resolve_hits()` 也只返回切块。`EvidenceReader` 只支持原文块或切块，详情接口和前端没有受控原图查看链路。

本次是跨检索、证据契约、API 和前端的架构扩展，不是重新解析或改变问答模型。

## 2. 方案选择与非目标

采用已同意的方案：让无文字切块页面作为独立“页图证据”参与中文视觉检索，复用已有模型、DocIR、快照和鉴权机制。

不采用以下替代方案：

- 先补 OCR：可以另行改善文本，但走势图等仍不能保证转成可靠文字，无法解决所有图片证据的定位与查看问题。
- 伪造文字切块或自动填写图表描述：污染原文和文本索引，可能把推测值当作证据。

本次不恢复付费服务、不新增依赖或调度器、不绕过 Office 安全阻止、不自动激活候选库。原 91 份在线库及其历史快照保持不变。三份 Office 异常、图谱补全、视觉相关性调优、正式准确率评测分别保留为后续事项。

## 3. 页面身份与数据兼容

从候选 manifest 引用的 DocIR 枚举真实物理页，生成视觉页清单。清单保存在候选目录的独立派生产物中，不修改 DocIR、chunks.jsonl 或原 manifest。

每项包含：快照 ID、文档 ID、文档版本、物理页码、来源显示名、页图引用、页图内容摘要、关联切块 ID，以及是否缺少解析块／文字的标记。无物理页码的 TXT 不创建虚构页面。

页身份由快照、文档 ID、版本及页码确定，以 `vp_` 命名空间区分原文块和切块。同名文件不能合并，不以显示名称查找原图。

复用当前证据记录中的定位字段存放页身份，但显式标记 `evidence_kind=page_image`；这不是原始 DocIR block，也不是 chunk。纯图片证据的 `chunk_id` 为空、`block_ids` 为空、`text` 为空。提示语由界面／回答格式化逻辑生成，不冒充原文。

有文字关联的视觉结果保持现有切块证据语义，并携带命中的视觉页码；多页切块的命中页不能被切块起始页覆盖。新元数据字段对历史证据可缺省，不要求改写历史记录或全表迁移。

## 4. 检索与回答行为

视觉索引枚举所有具有有效身份、实际可读页图的物理页，而不再以文字切块是否存在为前提。本次数据的预期范围为 17,957 页，实际失败必须逐项留痕，不能伪造成功。

有切块的页面继续返回关联切块；无切块的页面返回页图证据。两类结果均保留视觉分数、来源身份、页码，并在返回前应用版本可见性过滤。纯图片结果不得混入 BM25 或文本向量编码，因此 30,406 个文本切块无需重建。

页图证据可以进入现有融合与证据列表，但不能因为存在图片就视为问题已回答。付费暂停时，纯图结果显示“仅图像证据，未经文字解析／答案验证”，提供来源和查看入口；不自动推断金额、趋势或业务结论。混合结果中的真实文本摘录仍可使用，图片提示不能成为模型已验证文字。

保留旧视觉缓存，新索引使用不同的页身份／缓存格式版本。只有能核对模型、预处理、页身份与图片指纹时才复用向量；不通过拼接不同模型空间或猜测缓存行顺序实现复用。无法可靠复用时允许一次本地重编码，不重跑文档解析。

## 5. 受控证据详情与原图 API

复用 `GET /api/evidence/{evidence_id}`，增加证据类型、视觉页码和是否可查看图片等兼容字段。纯图片详情允许空文本，并保留正确的文档与页面定位。

增加 `GET /api/evidence/{evidence_id}/image` 返回经过校验的 PNG/JPEG 文件。请求只携带证据 ID，不接受客户端文件路径、任意 URL 或任意页码作为定位依据。

详情和图片共用授权与身份校验：

1. 校验登录身份及证据所有者／管理员权限，复用现有历史证据访问规则；未授权不泄漏存在性。
2. 核对证据快照、manifest、文档版本、DocIR 内容摘要和真实页码。检索时仅返回可见版本；历史证据不得借此访问其他用户记录。
3. 从受信任产物解析页图，核对保存的图片摘要；身份或内容变化返回完整性错误，不能回退至同名文件。
4. 规范化路径并限制在批准的解析产物目录内。本项目候选引用 `output/kb_v3/parsed` 下既有页图是有效情况，但不能放宽成任意磁盘文件读取。
5. 文件缺失返回 404，身份／摘要不一致返回 409；非法图片或越界引用拒绝访问。响应使用正确图片类型、禁止 MIME 猜测及共享缓存。

不将本机绝对路径作为前端图片 URL，不把访问令牌放在 URL 中。

## 6. 前端最小交互

在现有证据展开区域增加“查看原图”入口、图片预览、来源／版本／页码及纯图片提示。不新建图库或编辑器。

复用现有 Bearer 鉴权，以受控 fetch 获取图片 Blob，再生成浏览器对象 URL。关闭证据、切换会话或组件卸载时撤销对象 URL；加载失败显示错误，不显示其他证据的旧图片。保留文本全文查看，不影响旧证据。

## 7. 验收标准

先写失败测试，再实现；保持现有文本、视觉身份和权限回归用例。验收至少包括：

- 无切块但有页图的页面能建立真实向量并解析为页图证据；无物理页码的来源不产生伪页。
- 两份同名文档、同一文档不同版本、多个物理页不串源；多页切块命中页正确。
- 纯图片证据文本为空、类型明确；本地回答不包含伪造图表文字或数值。
- 删除／不可见版本不被新检索召回；未登录、跨用户证据、越界路径和篡改摘要不能读取原图。
- 旧文字证据仍可读，旧有文本切块数保持 30,406，旧缓存保留且不被错误复用。
- 候选库逐页对账：17,957 个物理页分别归为成功编码或明确失败，不能只检查总向量行数。
- 对此前排除的 144 页逐项核对身份与向量映射；针对已确认的两个图表页验证命中后的原图回查。该检查证明覆盖／定位，不将强制指定相似度的单元测试当作自然语言召回准确率。
- 用真实模型执行自然语言检索，记录相关结果与失败，不设“有结果即准确”的门禁。
- 隔离测试数据库中的 HTTP 冒烟验证详情和图片字节；前端构建与浏览器交互单独记录。无需切换线上数据库或活动快照即可执行。
- 最终复核付费开关、在线 91 份快照及无新定时任务；运行记录分别列出覆盖、功能、权限和质量状态。
